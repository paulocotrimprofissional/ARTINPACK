# 📦 ARTINPACK
### Sistema Web de Controle de Estoque

Projeto acadêmico desenvolvido para facilitar a organização, o cadastro e o acompanhamento de produtos em estoque, proporcionando maior controle das movimentações e das informações armazenadas.

---

## 📋 Sobre o Projeto

O **ARTINPACK** é um sistema web de controle de estoque desenvolvido como parte das atividades acadêmicas do curso de **Análise e Desenvolvimento de Sistemas**.

O projeto busca oferecer uma solução simples e organizada para o gerenciamento de produtos, contribuindo para a redução de erros nos registros e para a melhoria do acompanhamento do estoque.

## 🎯 Objetivos

- Facilitar o gerenciamento de produtos.
- Organizar as informações do estoque.
- Registrar movimentações de entrada e saída.
- Permitir consultas aos produtos cadastrados.
- Contribuir para a eficiência dos processos de controle de estoque.

## ⚙️ Funcionalidades do Projeto

O repositório contempla módulos destinados às seguintes operações:

- **Cadastro de produtos:** organização dos registros dos produtos.
- **Movimentação de estoque:** controle das entradas e saídas.
- **Consulta de estoque:** acesso às informações dos produtos.
- **Testes automatizados:** verificação de funcionalidades e rotas da aplicação.

## 💻 Tecnologias Utilizadas

- **Python:** linguagem principal de desenvolvimento.
- **Flask:** framework para desenvolvimento da aplicação web.
- **Pytest:** ferramenta utilizada para testes automatizados.
- **Git e GitHub:** versionamento e armazenamento do código-fonte.

## 🚀 Execução do Projeto

Para executar o projeto localmente, é necessário ter o Python instalado.

Clone o repositório:

```bash
git clone https://github.com/paulocotrimprofissional/ARTINPACK.git
```

Acesse a pasta:

```bash
cd ARTINPACK
```

Instale as dependências utilizadas pela aplicação:

```bash
pip install flask pytest
```

Inicie a aplicação:

```bash
python app.py
```

**Observação:** as instruções de execução deverão ser verificadas conforme a configuração final da aplicação.

## 🧪 Testes

O repositório contém o arquivo `test_app.py`, destinado aos testes automatizados.

Para executar os testes:

```bash
pytest
```
